Wikidot Web Editor Introduction

A browser-based editing environment for Wikidot source pages. It pairs CodeMirror-style editing with a Tampermonkey bridge so authors can write in a modern editor while still using Wikidot's native save, preview, and cancel actions.

How It Works

The editor is a bridge, not a replacement backend

Iframe editor

The web editor runs as an iframe loaded from the configured editor URL. It provides the writing surface and editor controls.

Textarea synchronization

The userscript reads the original Wikidot textarea, sends the content into the iframe, and writes editor changes back to the textarea.

Native Wikidot actions

Save, preview, cancel, and live preview still depend on Wikidot's own page controls. The script only makes those actions easier to reach.

How To Use Tampermonkey And Edit It

Install and customize the userscript

01

Install Tampermonkey

Add Tampermonkey to your browser, open its dashboard, and create a new userscript.

02

Paste the script

Copy the content of userscript/h2o2-wikidot-editor.user.js into the new script and save it.

03

Edit the editor URL

Change EDITOR_URL if you host the editor somewhere else, such as a local server or another GitHub Pages address.

var EDITOR_URL = 'https://your-site.example/editor/index.html';
04

Use it on Wikidot

Open a Wikidot edit page. The side panel should appear automatically and sync with the original page textarea.

Conclusion

A focused editor for Wikidot authors

The Wikidot Web Editor improves the writing experience while keeping the final publishing workflow inside Wikidot. With Tampermonkey, the editor can be opened directly beside the page being edited, making long-form Wikidot source easier to manage without changing how the wiki saves content.
